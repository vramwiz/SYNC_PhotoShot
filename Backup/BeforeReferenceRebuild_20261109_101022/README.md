# SYNC_PhotoShot / 写真撮影

Delphi 37.0 / Win64、AviUtl2 2.1.15 以上向けの開発版です。
グループは SYNC。単一の SYNC_PhotoShot.aux2 が「写真撮影」フィルターを登録します。
事前描画用の正式な SDK 編集ハンドルを取得するため .aux2 を使用します。
別の補助プラグインは不要です。旧 .auf2 と同時に配置しないでください。

## 使い方

1. フィルターオブジェクトに「写真撮影」を配置し、標準パラメータで演出を設定。
2. 登場時間＋撮影待機時間がオブジェクト長に収まるようにする。時間単位はフレーム。
3. 再生・書き出しを停止して「写真を準備」を押す。
4. 成功通知後は、撮影済み写真を使用して任意時刻へシーク・書き出しできる設計。
5. 「準備状態」で選択中の効果の写真を確認する。

専用設定画面はありません。準備・状態確認には標準ボタンと通知だけを使用します。
撮影画像はメモリ保持です。プロジェクトの開き直し、編集、シーン変更、
キャッシュ破棄の後は再準備してください。
安全優先で、元映像以外のパラメータ変更を含むオブジェクト更新でも全写真を無効化します。
外部ファイルを書き換えた場合などホストが通知しない変更も、手動で再準備してください。
時間設定への中間点等で撮影位置が変化した場合、準備対象時刻と一致しなければ取得を拒否します。

## 実装内容

- 現在のフィルター入力を取得したライブビュー。デスクトップ画面の撮影はしません。
- スマートフォン（縦・横）、コンデジ、一眼レフ、インスタントカメラ。
- 本体／内部／プレビューの独立座標、倍率、回転、透明度、内部トリミング・ぼかし。
- 6段階のフレーム時間、7種類の自動演出、11種類のシャッター。
- 背景ぼかし・暗さ、全体／白枠／インスタント写真風プレビュー。
- 写真準備では、対象効果の入口における加工前画像と当時の内部設定だけを採取。
- 最後に届くシーン合成画像は写真へ流用しません。
- scene/object/effect ID、要求token、絶対・相対frame、編集世代を照合。
- 編集・削除中の結果や古い完了通知は拒否。完了待ちは編集callback内で行いません。
- RhythmShooter由来の純Delphi MP3デコーダー。外部FFmpegは実行時不要。
- ユーザー提供4音を同梱。音量0..100、絶対サンプル同期、44.1/48kHz対応。

## ユーザー提供MP3

入力元はこのプロジェクトの Mp3 フォルダーです。元音源は変更しません。

| 種類 | ファイル |
| --- | --- |
| スマートフォン | Mp3\スマホ.mp3 |
| コンデジ | Mp3\コンデジ.mp3 |
| 一眼レフ | Mp3\一眼レフ.mp3 |
| インスタントカメラ | Mp3\インスタントカメラ.mp3 |

通常ビルド後は Plugin\SYNC_PhotoShot\Mp3 に元ファイル名のままコピーします。
以前の Assets\Audio の仮合成音は使用しません。
録音の正規化・増幅・切り詰めはしていません。

## 検証と未確認点

- Debug／Releaseビルド成功。時間、描画、MP3、音声混合、DLL模擬ホスト試験を実施。
- 写真準備は独立EXEの模擬SDKで、入力の取り違え、逆順、編集、複数対象、再入などを検証。
- これらは実際のAviUtl2での確認の代わりではありません。
- 実機の事前描画受付・callback再実行・複数同名効果の対象指定・出力時の結果は未確認。
- フィルターオブジェクト単体で音声callbackが呼ばれるかも未確認。
- 未準備／失敗時に現在画面を撮影済み写真として代用せず、写真表示を省略します。
- 写真は現在のプロジェクトへ保存されません。開き直した場合は必ず再準備が必要です。

指定外の追加プラグインによる実機検証は中止しました。
以後はPhotoShot本体と非プラグイン試験だけを対象とします。
通常のPluginフォルダーには未配備です。

## ビルド・出力

SYNC_PhotoShot.dproj を開くか note.md の手順を使用。
通常ビルドは C:\ProgramData\aviutl2\Plugin\SYNC_PhotoShot に aux2 と Mp3 を配置します。
旧 SYNC_PhotoShot.auf2 が配備先にある場合、重複登録を防ぐため配備を中止します。
旧版の扱いを確認してから手動で退避してください。

今回の検証ビルドは /p:PostBuildEvent= で自動配備を止めました。
プロジェクト内 Win64\Debug / Release に aux2 と Mp3 を生成しています。
旧ローカル auf2 は .auf2.previous として保持し、現行成果物と区別しています。
既存 Setup は旧Nicomea用のため実行しないでください。
