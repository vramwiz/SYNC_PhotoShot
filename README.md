# SYNC_PhotoShot（写真撮影）

AviUtl2 用の写真撮影演出フィルタープラグインです。グループは **SYNC**、表示名は **写真撮影**。通常の `.auf2` 形式で、単体配置に対応します。

> 開発中です。公開前に [ライセンス情報](LICENSE.md) と [第三者コンポーネント](THIRD_PARTY_NOTICES.md) を確認してください。現時点では本体の公開ライセンスと同梱音源の再配布条件の最終確認が残っています。

## 主な機能

- スマートフォン、コンパクトデジタルカメラ、一眼レフ、インスタントカメラの 4 種類。
- 縦・横向き、カメラ本体と内部映像の位置・大きさなどを独立調整。
- フェード、ズーム、スライド、回転、ポップ、バウンドなどの登場・退場演出。
- フラッシュ、暗転、アイリスなどのシャッター演出と写真プレビュー。
- 背景ぼかし、時間配分、シャッター音の調整。
- 4 種の MP3 シャッター音をプラグインへリソースとして内蔵。再生に FFmpeg は不要です。

設定には AviUtl2 標準のパラメーター欄を使用します。

## 動作環境・導入

- Windows 64 bit / AviUtl2 **2.1.15 以降**。2.1.16 で初期化・登録を確認しています。
- `SYNC_PhotoShot.auf2` を AviUtl2 の専用プラグインフォルダーへ配置します。
  現プロジェクトの配置先は `C:\ProgramData\aviutl2\Plugin\SYNC_PhotoShot\` です。
- AviUtl2 を再起動し、SYNC グループの「写真撮影」を使用します。
- 内蔵音源を使用する通常配布では、別の Mp3 フォルダーやデコーダー DLL は不要です。
- 旧 `.aux2` は使用しません。既存の `Setup/` は参考元 Nicomea 用のままなので、PhotoShot のインストーラーとして実行しないでください。

## 写真を準備する

1. 入力映像と各設定を決め、再生・書き出しを停止します。
2. 対象の「写真を準備」を押します。カーソルが撮影位置へ移動します。
3. その位置の通常描画で、このフィルターへ入る映像を写真として保持します。
4. 「準備状態」で完了を確認してから、シーク・再生・書き出しを行います。

カーソル移動だけでは準備完了とは限りません。未完了なら撮影位置で再描画してください。待機は 30 秒で解除されます。「写真を破棄（全て）」は全インスタンスの保存写真と待機を解除します。

**素材・設定を編集した後や、プロジェクトを開き直した後は再準備が必要です。** 写真はメモリー保持のみで、プロジェクトへの画像保存は行いません。背景内容のすべての変更を自動検出する仕組みではありません。待機中の書き出しは避けてください。複数インスタンスの写真は分離されますが、待機要求は一つで、新しい要求が古い要求を置き換えます。

## ビルド

Delphi 37.0 / Win64。IDE で `SYNC_PhotoShot.dproj` を開き、Debug または Release を選びます。

- 現設定ではビルド成果物を上記の Plugin フォルダーへ**直接出力**します。通常ビルドは配置済みファイルを更新するので、AviUtl2 を終了してから実施してください。
- ビルド後イベントは DLL → AUF2 コピー、コピー失敗時の停止、DLL 削除を一行ずつ記述しています。Release は RSM 削除も別行です。
- デバッガのホストパスは開発環境固有です。自分の AviUtl2 2.1.15 以降の実行ファイルへ合わせてください。
- 配備せず検証する場合は、MSBuild の `/p:DCC_ExeOutput=<検証用の絶対パス>` と `/p:PostBuildEvent=` を**併用**します。後者だけでは直接出力を止められません。
- 新規の補助プラグインは不要です。

### 音源の差し替え

`Mp3/` の 4 音を更新した場合は、`Resources/UpdateShutterResources.ps1` を明示実行してからビルドします。専用の `Source/Plugin/Filter/SYNC_PhotoShot_Audio.res` を更新し、以前のリソースを Backup に保存します。主 `SYNC_PhotoShot.res` とは別です。元 MP3 を再エンコードせず埋め込みます。詳細は [Resources/README.md](Resources/README.md)。

## 構成

| 場所 | 内容 |
| --- | --- |
| Source/Common | 描画・時間制御・写真保持・音声ミックス |
| Source/Plugin/Filter | フィルター本体・パラメーター・写真準備・音源リソース |
| Source/Lib/Smartphone | SYNC_Mine 由来のスマホ描画 |
| Source/Lib/Audio | 純 Delphi MP3 デコーダー |
| ThirdParty | ライセンス、移植元、変更記録 |
| Mp3 / Resources | 現在のシャッター音原本とリソース更新処理 |
| Image | 見た目の確認用テスト画像 |
| Assets/Audio | 初期の暫定合成音。現行の内蔵音とは別 |
| Tests | 開発時の検証とログ |

`Image/PhotoShot_Test_1920x1080.png` は灰色のポリゴン人形と色・階調パターンを含む AI 生成の確認用画像です。1920×1080 ですが、測色用に校正されたチャートではありません。色コードや各パッチの厳密な RGB 値を保証しません。

## 確認状況と注意

Debug / Release のビルド、模擬 SDK による描画・音声・写真準備、内蔵 MP3 と原本の一致、AviUtl2 2.1.16 での初期化・登録を確認しています。ユーザー環境で起動エラーが解消したとの報告があります。実ホストでの全演出・写真準備・音声・書き出しの組合せを網羅した確認ではありません。

初期化ログは `%LOCALAPPDATA%\SYNC_PhotoShot\initialize.log`。開発履歴は `note.md` と `Tests/` にありますが、過去の構成や古いホストパスも含むため、現在の操作はこの README を参照してください。
