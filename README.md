# SYNC_PhotoShot（写真撮影）

AviUtl2 で、カメラを構えて写真を撮る演出を加えるフィルタープラグインです。
グループは **SYNC**、表示名は **写真撮影**。単体配置にも対応します。

## できること

- スマートフォン、コンパクトデジタルカメラ、一眼レフ、インスタントカメラの切り替え。
- カメラの縦・横向きや、カメラ本体と内部映像の位置・大きさの調整。
- フェード、ズーム、スライドなどの登場・退場演出。
- フラッシュ、暗転、アイリスなどのシャッター演出。
- 撮影した写真のプレビュー、背景ぼかし、シャッター音の調整。

設定は AviUtl2 標準のパラメーター欄で行います。シャッター音は内蔵されているため、別途 MP3 ファイルや FFmpeg を用意する必要はありません。

## 動作環境

- Windows 64 bit
- AviUtl2 **2.1.15 以降**

## インストール

1. AviUtl2 を終了します。
2. `SYNC_PhotoShot.auf2` を次のフォルダーへ配置します。フォルダーがなければ作成してください。

   `C:\ProgramData\aviutl2\Plugin\SYNC_PhotoShot\`

3. AviUtl2 を起動し、SYNC グループの「写真撮影」を選びます。

更新するときも、AviUtl2 を終了してからファイルを置き換えてください。

## 使い方

1. 撮影したい映像に「写真撮影」を配置します。
2. 「カメラ種類」「カメラ方向」を選び、カメラ本体と内部映像の位置・大きさを調整します。
3. 登場・撮影・退場の時間や、シャッター演出、写真の表示方法、音声を設定します。
4. 再生・書き出しを停止し、対象の **「写真を準備」** を押します。カーソルが撮影位置へ移動します。
5. 撮影位置の映像が描画されると、このフィルターへ入力される映像が写真として保持されます。
6. **「準備状態」** を押し、AviUtl2 のログで完了を確認してから、再生・シーク・書き出しを行います。準備の移動・完了・失敗もログへ通知し、メッセージボックスでは処理を止めません。

### 白枠付きプレビューが見えない場合

「写真を準備」は撮影位置へ移動します。写真プレビューはシャッター演出と退場が終わった後から始まるため、撮影位置のままでは白枠は表示されません。準備完了後、プレビューの開始位置より先へ移動してください。既定の時間設定では、対象オブジェクトの先頭から約2.17秒後（30 fpsでは65フレーム後）に開始します。登場演出の開始瞬間は透明な場合があります。

未準備・プロジェクト再読込後は写真自体が表示されません。「準備状態」を確認してください。プレビュー位置・倍率・回転によって白枠が画面外に出る場合は、中央・倍率100・回転0に戻して確認できます。

### 写真の準備が完了しない場合

カーソルが移動しただけでは、準備完了にならない場合があります。撮影位置で映像を再表示してください。待機は 30 秒で解除されるため、必要なら「写真を準備」を押し直してください。

複数の「写真撮影」を使う場合は、一つずつ準備の完了を確認してください。同時に待機できるのは一つで、新しい準備操作が前の待機を置き換えます。

### 写真を撮り直す・破棄する

- **素材や設定を変更した後は、もう一度「写真を準備」を押してください。**
- **プロジェクトを開き直した後も、写真の再準備が必要です。** 準備した写真はプロジェクトに保存されません。
- 「写真を破棄（全て）」を押すと、配置したすべての「写真撮影」の保持写真と待機を解除します。
- 写真の準備が完了するまでは、書き出しを開始しないでください。

## 時間設定（秒）

6つの時間は名前末尾に「（秒）」が付き、0.01秒刻みで0～600秒を指定します。
初期値は登場0.50秒、撮影待機1.00秒、シャッター0.27秒、退場・切替0.40秒、プレビュー登場0.50秒、プレビュー保持1.00秒です。

0.01秒は入力精度です。実際の映像の境界はシーンのfpsに従って最寄りフレームへ丸めます。
各段階の時間を個別に丸めず、先頭からの累積秒を丸めるため、短い時間を重ねても丸め誤差が累積しません。
正の短い時間でも、そのfpsでは0フレームとなり省略される場合があります。
シャッター音もこの撮影フレームに合わせるため、指定秒との差は最大約半フレームです。
fpsを変更した場合は写真を再準備してください。

旧版のフレーム指定値を新しい秒として扱わないよう、時間項目の名前を変更しています。
旧版で保存した時間・時間の中間点は自動移行しません。更新前に控えを取り、新しい秒項目へ再指定してください。
旧版の値を秒に直す目安は「旧フレーム数 × シーンのScale ÷ Rate」です。
実AviUtl2での旧プロジェクト保存・再読込による移行挙動は未検証です。

## 注意事項

開発中のプラグインです。大切なプロジェクトはバックアップしてから使用してください。

同梱の `Image/PhotoShot_Test_1920x1080.png` は、見た目を確認するための AI 生成画像です。測色用の校正チャートではなく、厳密な色の検査には使用できません。

### 仮想カメラの撮影範囲

カメラを画面上に置いた位置・角度・倍率から、画面部分の背後の映像を写真にします。内部X/Y・内部ズーム・内部ぼかしも反映し、ライブ表示と写真で同じ範囲を使います。映像の外へ出た部分は黒になります。カメラ方向の縦横切替はスマートフォンで反映されます。

撮影時の構図と加工を保持するため、撮影後にカメラの設定を変えても準備済みの写真内容は変わりません。撮り直す場合は再準備してください。プレビュー位置・倍率・角度・枠方式は写真の表示方法を変える設定です。

写真にはカメラ別の表示や仮の撮影数値を重ねます。実際の撮影機器の測定値やEXIFではありません。背景の暗さ・ぼかしは写真に焼き込みません。撮影日入力はまだ追加していません。
