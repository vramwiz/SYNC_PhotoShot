# SYNC_PhotoShot

AviUtl2 用「写真撮影」フィルタープラグイン。グループ名は SYNC。
Delphi 37.0 / Win64、AviUtl2 2.1.15 以降。

## 現在の構成

SYNC_Nicomea.dpr / .dproj の実ファイルを正解として通常の auf2 形式に戻した。
名称・PhotoShot のユニット参照以外はコピー元のプロジェクト設定構造と値を保持する。
DLL 境界もコピー元と同じ InitializePlugin / UninitializePlugin / GetFilterPluginTable の3関数。
元プロジェクトは変更していない。

カメラ4種、7つの動作、11のシャッター選択、3つの写真プレビュー方式、6段階の時間、
カメラ・内部映像・写真の変形、背景処理、シャッター音を実装。
スマホ描画は SYNC_Mine、純 Delphi MP3 デコーダーは SYNC_RhythmShooter を参考に再利用した。

## 写真を準備する

1. 元映像と各設定を決め、再生・書き出しを止める。
2. 対象エフェクトの「写真を準備」を押す。撮影フレームへカーソルを移動する。
3. そのフレームの通常描画で、加工前のフィルター入力だけを写真として確定する。
4. 「準備状態」で準備済みを確認してから、自由なシーク・書き出しを行う。

カーソル移動だけでは描画完了の保証はない。未完了なら撮影位置へ移動して再描画する。
30秒で待機を解除する。「写真を破棄（全て）」は全インスタンスの保存写真と待機を解除する。
誤った時刻・対象・参照シーン・モーションブラー用描画を写真として採用しない。
準備成功後も通常描画を継続する。入力が得られなければ現在映像を写真として偽装しない。

元映像や設定を編集した後は必ず再準備する。
撮影時刻・範囲・寸法変更は検査するが、背景内容の変更すべてを自動検知する仕組みはない。
写真はメモリ保持のみ。プロジェクトを開き直した場合も再準備が必要。
準備待ち中は書き出さない。auf2 API だけでは書き出し状態を完全識別できない。
各インスタンスの写真は分離し、待機要求は一つ。新しい要求は古い待機を取り消す。

## 音源

ユーザー提供の Mp3 フォルダー内4音を、そのまま専用リソースへ埋め込む。
Source/Plugin/Filter/SYNC_PhotoShot_Audio.res を音声ユニットからリンクする。
主 SYNC_PhotoShot.res はコピー元と同じ96バイトを保持。ビルド設定の変更は不要。
元音源と埋込バイト・デコードPCMの一致を検証済み。再エンコードはしない。
音源を差し替えたら Resources/UpdateShutterResources.ps1 を明示実行し、その後ビルドする。
既存のリソースは毎回 Backup に保存される。

## ビルド・配置

通常 IDE ビルドは元と同じビルド後イベントで、
C:\ProgramData\aviutl2\Plugin\SYNC_PhotoShot\SYNC_PhotoShot.auf2 へコピーする。
検証ビルドは /p:PostBuildEvent= を指定して自動配備を止める。
今回の成果物は Win64/Debug と Win64/Release の SYNC_PhotoShot.auf2。
内蔵音源を使うため、配布に別 Mp3 フォルダーは不要。

既存 Setup は Nicomea 用のまま保護してあり、実行しない。
