# SYNC_PhotoShot（写真撮影）

AviUtl2でカメラを構え、シャッターを切る演出を加えるフィルタープラグインです。
グループは **SYNC**、表示名は **写真撮影** です。

ここでのプレビューは、カメラ本体内に表示するライブビューです。
撮影した写真の保存・白枠表示・撮影結果プレビューは行いません。写真準備も不要です。

## できること

- スマートフォン表示と、それ以外の全画面ファインダー表示の2系統。コンパクトデジタルカメラ・一眼レフ・インスタントカメラは撮影中の表示と音で区別します。
- カメラ本体の位置・倍率・角度と、内部映像の移動・ズーム・ぼかし。
- 共通の「カメラ・枠色」。スマホ本体の色と、他カメラのファインダー枠に同じ色を使います。
- カメラ別の表示や仮の撮影数値。実際のEXIFや測定値ではありません。
- 登場・待機・シャッター・退場演出と内蔵MP3シャッター音。
- 背景のぼかし・暗さ。カメラ方向の縦横切替はスマートフォンに適用します。

## インストール

Windows 64 bit、AviUtl2 2.1.15以降で使用します。
AviUtl2を終了してから、SYNC_PhotoShot.auf2を次へ配置・更新してください。

C:\ProgramData\aviutl2\Plugin\SYNC_PhotoShot\

## 使い方

1. 対象映像にSYNCの「写真撮影」を配置します。
2. カメラ種類と位置・倍率・角度を設定します。
3. 撮影前・撮影中・撮影グループで演出と時間を調整します。
4. 通常どおり再生・シークします。写真準備やカーソル移動操作はありません。

スマホは中央を撮影範囲とし、横向きは左右、縦向きは上下に細めの暗い操作領域に分けます。シャッターボタンは横向きの右側、縦向きの下側に表示します。撮影像は毎フレーム更新します。他カメラには別の筐体を描かず、スマホと共通の角丸枠を画面全体へ適用します。中央・倍率100で全画面の撮影範囲となり、縮小すると周囲の元映像が見えます。
撮影範囲の映像を、位置・角度・倍率から計算して内部に表示します。
内部X/Y・ズーム・ぼかしも反映し、映像範囲の外は黒になります。
シャッター後もカメラ内は現在の映像を表示したまま退場演出を行い、静止写真へは切り替えません。退場時間を0秒にすると、シャッター演出が終わった時点でカメラが一瞬で消えます。

## 時間設定

時間は「（秒）」付きの4項目で、0.01秒刻み、0～600秒です。
初期値は登場0.50秒、撮影待機1.00秒、シャッター0.27秒、退場・切替0.40秒。
シーンfpsに従い累積時刻を最寄りフレームへ丸め、音声も撮影フレームに合わせます。
0.01秒は入力精度で、短い時間は0フレームになる場合があります。

旧フレーム指定の時間は自動移行しません。秒で再指定してください。
写真結果向けの旧プレビュー設定・準備ボタンは廃止され、現在の表示には使用しません。
実AviUtl2での旧プロジェクト再読込は未検証です。
