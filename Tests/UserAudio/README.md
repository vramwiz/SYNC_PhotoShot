# ユーザー指定音源の検証

Mp3 フォルダーの4音をそのまま使用します。元ファイルを変換・編集・上書きしていません。
実行時の読み込み先はプラグイン DLL と同じフォルダーの Mp3 サブフォルダーです。

- 種類0: スマホ.mp3
- 種類1: コンデジ.mp3
- 種類2: 一眼レフ.mp3
- 種類3: インスタントカメラ.mp3

UserAudioTests.dpr は入力を読み取るのみです。
純 Delphi MP3Decoder と製品用 DecodePhotoShotMP3 の双方で検証しました。
結果は results.txt、コピー検証は copy-verification.txt、元のSHA256は source-hashes.json。

全音は44.1kHz stereo。スマホ・コンデジ・一眼レフは3秒、インスタントは5秒。
コンデジと一眼レフのデコード結果は最大絶対振幅1に達します。正規化や追加増幅はしていません。
先頭有音は PCM16 1段階を超えるしきい値で測定しており、聴感上の立ち上がり検出ではありません。

この単体検証は AviUtl2 での単体音声出力確認ではありません。
仮合成音 Assets/Audio は参照しなくなっていますが、削除はしていません。
